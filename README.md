# Nitish Kumar — Portfolio

Frontend-only portfolio (Vite + React + Three.js). No backend required.

## Setup

```bash
npm install
npm run dev
```

## Update content anytime

Edit these files, then refresh:

| Content | Path |
|---------|------|
| Profile / About / Skills / Experience / Education / Certificates | `src/data/resume.ts` |
| Selected projects | `src/data/projects.ts` |
| Resume PDF | `public/resume.pdf` |
| Profile photo | `public/profile.png` |
| Certificate images/PDFs | `public/certificates/` |

## Contact

The contact form uses `mailto:` (opens the user’s email app). No API key needed.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run preview` — preview build
